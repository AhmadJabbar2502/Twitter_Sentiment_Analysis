# Twitter_Sentiment_Analysis

The Streamlit application developed for this project can be accessed via the following URL: https://is.gd/AQ7X9l </br>

This project presents a comprehensive analysis of Twitter sentiment patterns, user engagement metrics, and temporal trends using a dataset of 10,000 tweets spanning from January to April 2023. Through advanced text processing, sentiment analysis, and data visualization techniques, we developed a multi-faceted understanding of how sentiment influences engagement on the Twitter platform.  </br>

Our analysis reveals that sentiment significantly impacts engagement metrics, with positive tweets receiving 18-22% higher engagement rates compared to negative tweets. The project culminates in an interactive Streamlit dashboard that enables stakeholders to explore sentiment patterns, track engagement trends, and identify influential users in real-time.
